# emad


## PHP Version

This repository also contains a basic PHP implementation in the `php/` directory.
The CLI script supports adding students and courses and enrolling students in courses.

Example usage:

```bash
# Add a student
php php/cli.php add-student S1 "Alice"

# Add a course
php php/cli.php add-course C1 "Math 101"

# Enroll a student in a course
php php/cli.php enroll S1 C1
```
